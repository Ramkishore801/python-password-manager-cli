# Python Password Manager (CLI)

This is a simple command-line password manager built using Python.

## Features
- User Registration & Login
- Password Generator
- Save Passwords (File-based storage)
- View Saved Passwords
- Error Handling

## How It Works
- User data is stored in `users.txt`
- Passwords are stored in `vault.txt`
- Login is required to access saved passwords

## How to Run
1. Make sure Python is installed
2. Run:
   python main.py

## Concepts Used
- Functions
- File Handling
- Loops & Conditions
- Exception Handling
